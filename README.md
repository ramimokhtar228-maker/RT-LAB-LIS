## 🌟 نظرة عامة على المشروع (Project Overview)
نظام معلومات مختبرات طبية متكامل وشامل (Laboratory Information System - LIS) مصمم وفق أحدث المعايير الطبية الدولية للجودة والدقة (ISO 15189 / CLSI).
يعمل النظام محلياً وبشكل سحابي (PWA & Offline-First) لإدارة دورة العمل المعملية بالكامل من لحظة حجز المريض أو سحب العينة وحتى اعتماد التقرير الطبي إلكترونياً.

---

## 🚀 المميزات الرئيسية للمنظومة
1. **دليل التحاليل الطبية الموسع (147+ تحليلاً طبياً معتمداً):**
   - كيمياء الدم الكاملة (Kidney, Liver, Lipid, Cardiac, Electrolytes).
   - صورة الدم الكاملة (CBC مع Differential كامل وتنبيهات القراءات الحرجة).
   - الهرمونات والمناعة (Thyroid, Fertility, Tumor Markers, Vitamins, Immunology).
   - السكر التراكمي والفحوصات الدورية مع نطاقات مرجعية مخصصة حسب العمر والجنس.
2. **شاشة الحجوزات الطبية والمواعيد:**
   - إدارة طلبات الحجز المسبق ومواعيد سحب العينات بالمعمل أو الزيارات المنزلية مع تحويل مباشر لأوامر فحص.
3. **باركود العينات وسلسلة الحيازة (Sample Tracking & Barcoding):**
   - توليد باركود فريد وتحديد أنواع الأنابيب (EDTA, Serum, Heparin, Sodium Citrate) ومواقع الحفظ.
4. **شاشة إدخال النتائج الذكية (Smart Worklist):**
   - فحص تلقائي وتلوين للقيم العادية والحرجة (Critical / Panic Flags: High & Low).
   - اعتماد فوري من الاستشاري (Clinical Pathologist Verification).
5. **طباعة وتصدير التقارير الطبية بمعيار A4 الدولي:**
   - **طباعة PDF مباشرة:** بهوامش دقيقة وتنسيق طبي معتمد يحمل ترويسة المعمل والشعار والباركود.
   - **تصدير شرائح PowerPoint (A4 Portrait):** إمكانية حفظ التقرير بصيغة PPTX طبية بدقة فائقة.
6. **المنظومة المالية والمخازن والموارد البشرية:**
   - حساب إجمالي الفواتير، المدفوعات، البواقي، والمصروفات التشغيلية.
   - كشوف مرتبات الموظفين ومتابعة كواشف ومحاليل المعمل وتنبيهات الصلاحية وإعادة الطلب.
7. **النسخ الاحتياطي والمزامنة السحابية:**
   - إمكانية تصدير واستيراد نسخة احتياطية مشفرة لكافة بيانات المعمل (JSON).
   - تطبيق ويب تقدمي (PWA) قابل للتثبيت كبرنامج على أجهزة الكمبيوتر والهواتف الذكية بدون اتصال بالإنترنت.

## 💻 متطلبات التشغيل والبدء السريع (Quick Start)

### المتطلبات الأساسية:
- **Node.js**: الإصدار 18 أو أحدث (موصى بـ Node.js 20 LTS).
- **npm** أو **bun**.

### خطوات التشغيل المحلي:
1. قم بفك ضغط ملف المشروع أو استنساخه:
   ```bash
   git clone https://github.com/ramimokhtar228-maker/RT-LAB-LIS.git
   cd RT-LAB-LIS
   ```

2. قم بتثبيت الحزم البرمجية:
   ```bash
   npm install
   ```

3. تشغيل خادم التطوير المحلي:
   ```bash
   npm run dev
   ```
   سيفتح المشروع فوراً على العنوان المحلي: `http://localhost:3000`

4. بناء نسخة الإنتاج النهائية:
   ```bash
   npm run build
   ```
   تُنشأ الملفات المجهزة للتشغيل في المجلد `dist/`.

## 🌐 النشر التلقائي على GitHub Pages (GitHub Deployment)
المستودع مجهز بملف **GitHub Actions Workflow** تلقائي (`.github/workflows/deploy.yml`):
1. بمجرد رفع الكود إلى فرع `main` في مستودع GitHub.
2. توجه في GitHub إلى: **Settings** > **Pages**.
3. تحت خيار **Build and deployment > Source**، اختر **GitHub Actions**.
4. سيتم بناء ونشر الموقع تلقائياً على الرابط:
   `https://ramimokhtar228-maker.github.io/RT-LAB-LIS/`
